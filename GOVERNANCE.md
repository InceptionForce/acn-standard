# Governance for the development draft

ACN Standard is currently incubated by InceptionForce and is not represented as
an independent industry standard.

Normative changes require:

1. a written problem statement and compatibility impact;
2. corresponding JSON Schema changes;
3. at least one valid or invalid conformance scenario;
4. reference SDK support; and
5. two maintainers approving the change before a stable release.

A feature cannot become stable until two independent implementations pass its
conformance scenarios. InceptionForce-specific behavior must use a namespaced
extension and cannot silently become a normative requirement.

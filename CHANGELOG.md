# Changelog

## 0.1.0 - 2026-08-16

- Initial ACN procurement, payment, fulfillment, cancellation, and dispute contracts.
- Ed25519 envelope security profile and conformance suite.
- Direct HTTP and formal A2A 1.0 protocol bindings.
- Python and TypeScript client SDKs.

Changes follow semantic versioning. Breaking contract changes require a new protocol
major version and a documented migration period.
